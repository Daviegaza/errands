# Tuma

Tuma is a polished, frontend-only errand marketplace demo built with React, TypeScript, Vite, React Router, Tailwind CSS, Framer Motion, Zustand, React Hook Form, Lucide icons, and Recharts.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The app signs into a mock account automatically. Use the **Need Help / Earn Money** switcher to explore both requester and runner experiences. All task, offer, messaging, tracking, rating, status, and withdrawal interactions are simulated in local frontend state.

## Brand

The temporary brand name and mark live in `src/components/navigation/AppShell.tsx`. Core brand tokens are defined near the top of `src/styles.css`, making the identity straightforward to rename or recolor.
